# Milaan ERP

Billing, stock, GST, banking and loans for small businesses.

Download the latest installer from [Releases](https://github.com/HarshGaba1196/milaan-erp-releases/releases/latest):

- Mac (Apple chip): `Milaan-ERP-<version>-mac-arm64.dmg`
- Mac (Intel): `Milaan-ERP-<version>-mac-x64.dmg`
- Windows: `Milaan-ERP-<version>-windows-setup.exe`

Installed copies update themselves.
